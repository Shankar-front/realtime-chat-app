# Realtime Chat Application

A full-stack realtime chat application built using React.js, Node.js, Express.js, Socket.io, and SQLite.

---

# Features

- User Registration & Login
- JWT Authentication
- Realtime Messaging
- Multiple Chat Rooms
- Online Users List
- Typing Indicator
- SQLite Database Integration
- Socket.io Realtime Communication
- Responsive Chat UI

---

# Tech Stack

## Frontend
- React.js
- Vite
- Socket.io Client
- Axios
- React Router DOM

## Backend
- Node.js
- Express.js
- Socket.io
- SQLite
- JWT Authentication
- bcryptjs

# Installation

## Clone Repository

```bash
git clone YOUR_GITHUB_REPO_LINK
```

---

# Backend Setup

```bash
cd server
npm install
npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```

---

# Frontend Setup

```bash
cd client
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# Database

SQLite database is automatically created when backend starts.

Database file:

```bash
chat.db
```
